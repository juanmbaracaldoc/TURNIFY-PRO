
1. Install Python

2. Create virtual env
python -m venv venv

3. Activate
venv\Scripts\activate

4. Install packages
pip install -r requirements.txt

5. Put firebase_key.json inside backend folder

6. Run migrations
cd backend
python manage.py makemigrations
python manage.py migrate

7. Run server
python manage.py runserver

Pages:
/ -> cliente
/employee -> empleado
/screen -> pantalla banco
/dashboard -> dashboard
